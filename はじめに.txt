kotonoha 自己判定版 1.1

【GitHubに置く場合】
このフォルダー内の index.html、manifest.webmanifest、icons フォルダーを、今までの index.html と同じ場所へ上書きしてください。
index.html には JavaScript と CSS をすべて組み込んであります。古い app.js や CSS が残っていても読み込みません。
icons と manifest.webmanifest はホーム画面アイコン用です。

【ローカルの場合】
index.html をブラウザーで開いてください。学習画面の動作はこの1ファイルで完結します。

【更新の確認】
ページ下部に「kotonoha · 自己判定版 1.1」と表示されます。
復習は「答えを見る」の後に○・×のボタンを選ぶ方式です。
表示が古い場合はGitHubの公開処理が完了してからSafariで同じURLを再読み込みしてください。
保存済みデータを守るため、サイトデータの削除はしないでください。
更新前に「データと設定」からバックアップしておくと安心です。
